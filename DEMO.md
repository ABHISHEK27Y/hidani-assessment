# Four-minute assessment demo

Use a synthetic or consented resume with readable text. Record the deployed URL and browser address bar so the live link is visible.

| Time | Action and narration |
|---|---|
| 0:00–0:30 | Open the live URL. Say that Orbit is a conversational job assistant backed by 1,800 real, attributed listings. Show the job count. |
| 0:30–1:15 | Upload a PDF resume, then briefly show the parsed name, contact, designation, skills, experience, education, and projects. Mention DOCX support and unreadable-file handling. |
| 1:15–2:05 | Walk through the recommended cards and the match reasons. Ask “show only remote roles” and “jobs needing React” in the chat. |
| 2:05–2:55 | Say “apply to job 3.” Show that the original application URL opens and the job is recorded once as awaiting external submission. Explain that external sites require their own submission. |
| 2:55–3:30 | After completing the external flow or in a clearly labeled demo, confirm “I submitted job 3.” Ask “show my applied jobs”; show the status and date. |
| 3:30–4:00 | Show the public repository's scraper, JSON catalogue, architecture diagram, and tests. Mention that the optional LLM uses a strict function call for ambiguous intent while the tools own all factual and stateful operations. |

Before recording, verify the live `/health` endpoint, the public repository URL, and one working source/application link. Keep the file picker and any API key or account secrets out of the recording.
